# Slide Content Drafts

One markdown file per slide. Naming convention:

`NN_slide_name.md` (e.g., `01_aivc_architecture_hero.md`, `08_roadmap_28mo.md`)

Format per file:

```
# Slide title

- Maps to Kinga's deck: Slide N (or "New")
- Section: Hero / Validation / Architecture / Roadmap / Risk / Ask
- Visual lead: Diagram / Chart / Photo / Text-only
- Status: Draft / Reviewed / Ready for generation

## Headline

One-sentence slide thesis.

## Body content

- Bullet
- Bullet
- Bullet

## Visual spec

What the diagram/chart should show. Pointer to assets/diagrams/<name>.svg once generated.

## Notes for design

Anything special about layout, emphasis, color usage.

## Source data / claims

Where each technical claim comes from (commit SHA, paper, validation result).
```
